# Baby-Line-Bot

這是一個用來記錄寶寶生理時鐘的 LINE 機器人：可以記錄睡眠、吃奶／副食品、排泄、體溫和備註，也能查每日統計。

- **完全免費**：只用你的 Google 帳號（Google 試算表 + Apps Script），不用註冊其他服務。
- **資料在你自己的 Google 試算表裡**：手機打開就能看、能改、能畫圖表。
- **不會休眠斷線**：Google 的伺服器隨時都醒著。
- 把機器人加進「爸爸＋媽媽」的 LINE 群組，大家記的都是同一個寶寶的紀錄。

## 怎麼使用

### 記錄
| 類別 | 輸入範例 | 說明 |
|---|---|---|
| 睡眠 | `睡覺` → `起床` | 起床時自動算出睡了多久 |
|  | `睡 13:00-14:30`、`睡 22:00-06:00` | 補登一段睡眠（可以跨夜） |
| 吃 | 點「🍼 餵奶」按鈕 → 選種類 → 選份量 | 不用打字，三下就記好 |
|  | `配方奶 150`、`瓶餵母乳 90`、`喝奶 120` | 沒寫單位的話預設是 ml |
|  | `母乳 左 15` | 親餵，數字代表分鐘 |
|  | `副食品 30g 南瓜粥` |  |
| 排泄 | `尿布 尿`、`尿布 便`、`尿布 尿+便`、`尿尿`、`大便` |  |
| 體溫 | `體溫 37.2`，或直接打 `37.2` | 37.5 以上提醒偏高，38 以上提醒發燒 |
| 洗澡 | `洗澡` |  |
| 擠奶 | `擠奶 120`、`擠奶 左 60 右 50` | 會顯示今天共擠多少 |
| 吃藥 | `吃藥 退燒藥 2.5ml`、`藥 益生菌 1包` | 會顯示距離上次吃同一種藥多久、今天第幾次 |
| 身高體重 | `體重 6.2`（或 `體重 6200`）、`身高 62`、`頭圍 40` | 會顯示比上次增加多少，並更新成長曲線圖 |
| 疫苗 | `疫苗 五合一 第一劑` |  |
| 看診 | `看診 小兒科 感冒 開藥` |  |
| 備註 | `備註 今天第一次翻身` |  |
| 補登時間 | `14:30 喝奶 120`、`尿布 便 09:15` | 時間比現在晚的話，會當成昨天 |
| 補登其他天 | `10/6 14:30 配方奶 120`、`10/6 睡 13:00-14:30` | 前面加日期，要寫時間 |
| 忘了按起床 | `起床 07:30` | 睡眠超過 6 小時還沒起床，記別的東西時 bot 會提醒 |

### 🍼 用按鈕記錄餵奶
1. 點回覆下方的「🍼 餵奶」按鈕（或打 `餵奶`）。
2. 選種類：🤱 親餵／🍼 瓶餵母乳／🥛 配方奶／🥣 副食品。
3. 選份量：
   - 瓶餵和配方奶：以**上次的量**為中心（標 ⭐），列出 ±30ml 的選項；第一次使用時列出 60～240ml。
   - 親餵：選左／右／雙邊和時間（10、15、20、30 分鐘）。
   - 不想記份量就按「✔️ 不記量」。
   - 其他份量直接打字，例如 `配方奶 135`。

要補登時間的話，打 `14:30 餵奶`，之後按的按鈕都會記在 14:30。

### 🔮 預測下一餐
每次記錄喝奶後，bot 會根據最近 3 天的紀錄，預測下一餐的時間和建議奶量：

```
✅ 已記錄
🍼 01:30 喝奶 130ml
距離上一餐 2小時50分

🔮 預計下一餐：約 04:30（04:15～04:45）
   建議準備：約 130ml
```

- 白天和夜間（22:00～06:00）的間隔分開計算。
- 要累積幾餐（約 1～2 天）才會開始預測。
- 輸入 `狀態` 也會顯示還有多久到下一餐。
- 預測只是參考，請以寶寶的實際反應為主。

### 📈 作息報表（網頁）
輸入 `報表`（或點「📈 報表」按鈕），bot 會回一個只屬於你們聊天室的連結，在 LINE 裡就能打開：

- **今日摘要**：奶量、睡眠、尿布、體溫、預計下一餐
- **24 小時作息圖**：最近 7 天，每天一列，睡眠、餵奶、尿布標在時間軸上
- **每日趨勢**：7／14／30 天的奶量、睡眠時數、餵奶間隔、尿布次數，也能展開成表格
- **成長曲線**：體重、身高、頭圍。設定生日和性別後，體重會對照 WHO 第 3～97 百分位
- **⚠️ 可能漏記**：白天超過 4.5 小時、夜間超過 6.5 小時沒有餵奶紀錄，會列出來提醒
- **補登**：點「＋ 補登紀錄」、點作息圖的空白處，或點漏記提醒的「補登」，就能補記餵奶、睡眠、尿布、體溫、體重。網頁補登的紀錄在試算表的「記錄者」欄會寫「網頁補登」

> 這個連結可以看和新增紀錄，**不要轉傳給其他人**。

### 👶 寶寶資料
| 輸入 | 說明 |
|---|---|
| `設定 生日 2026/8/5` | 報表會顯示出生第幾天，體重曲線用月齡對照 WHO 標準 |
| `設定 性別 男`（或 `女`） | WHO 標準男女不同 |
| `設定 名字 小寶` | 顯示在報表上 |
| `設定` | 看目前的設定 |

### 查詢
| 輸入 | 說明 |
|---|---|
| `今天`、`昨天` | 當日統計圖卡（附「看完整報表」和「看明細」按鈕） |
| `今天明細`、`昨天明細` | 當天每一筆紀錄 |
| `最近` | 最近 10 筆 |
| `狀態` | 距離上次吃、睡、換尿布、吃藥多久，以及預測下一餐 |
| `成長紀錄` | 身高、體重、頭圍的變化 |
| `疫苗紀錄`、`看診紀錄`、`吃藥紀錄` | 列出所有這類紀錄 |
| `擠奶紀錄`、`洗澡紀錄`、`體溫紀錄`、`備註紀錄` | 同上 |
| `說明` | 顯示使用說明 |

### 修改與刪除
| 輸入 | 說明 |
|---|---|
| `修改 喝奶 150` | 把最後一筆改成新的內容（時間不變） |
| `修改 14:30` | 只改最後一筆的時間 |
| `修改 14:30 喝奶 150` | 時間和內容一起改 |
| `復原` | 刪除最後一筆 |

也可以直接打開試算表修改任何一筆。

### 匯出
`匯出`（最近 7 天）或 `匯出 30`（最近 30 天）會在你的 Google 雲端硬碟建立一個新的試算表，包含「每日統計」和「明細」兩個分頁，bot 會回傳連結。要給醫生看的話，打開後按「共用與匯出」就能下載成 PDF 或 Excel。

### 📈 成長曲線圖
記錄身高、體重或頭圍時，試算表的「**成長曲線**」分頁會自動更新，裡面有體重、身高、頭圍三張折線圖。

---

每則回覆下方都有快速按鈕，常用的動作點一下就好。在群組裡，看不懂的訊息機器人不會回應，所以聊天不會被打擾；一對一聊天時則會提示「看不懂」，免得以為已經記好了。

試算表的「記錄者」欄會顯示記錄的人的 LINE 名字（舊的紀錄維持原本的 ID）。

## 安裝（全程用電腦操作，約 15 分鐘）

### 事前準備：LINE 官方帳號
1. 在 [LINE 官方帳號管理後台](https://manager.line.biz/) 建立官方帳號（免費方案）。
2. 到 **設定 → Messaging API**，按 **啟用 Messaging API**。
3. 到 [LINE Developers Console](https://developers.line.biz/console/) → 你的 channel → **Messaging API** 分頁最下面，在 **Channel access token** 按 **Issue**，複製起來。
4. 在官方帳號後台的 **設定 → 回應設定**：把「自動回應訊息」**關閉**，「Webhook」**開啟**。
5. 在 **設定 → 帳號設定**：把「加入群組或多人聊天室」改成**接受邀請**。

本 bot 只會「回覆」訊息、不會主動推播，回覆訊息不算官方帳號的訊息則數，所以完全免費。

### 步驟 1：建立試算表並貼上程式
1. 打開 [Google 試算表](https://sheets.new)，建立一個新的試算表，取名「寶寶紀錄」。
2. 上方選單：**擴充功能 → Apps Script**。
3. 把編輯器裡原本的內容全部刪掉，貼上這個 repo 的 [`Code.gs`](Code.gs) 全部內容。
4. 找到最上面這一行，把引號裡的字換成你的 Channel access token：
   ```js
   const LINE_CHANNEL_ACCESS_TOKEN = '把你的 Channel access token 貼在這裡';
   ```
5. 按 💾 儲存。

### 步驟 2：執行一次 setup（授權）
1. 在編輯器上方的函式下拉選單選 **setup**，按 **▶ 執行**。
2. 會跳出「需要授權」→ 按 **審查權限** → 選你的 Google 帳號。
3. 如果出現「**Google 尚未驗證這個應用程式**」：按左下的 **進階** → **前往「(專案名稱)」（不安全）**。
   這是因為這個程式是你自己寫的，沒有送 Google 審核，屬於正常現象。
4. 按 **允許**。
5. 回到試算表，會看到多了一個「紀錄」工作表。token 也會存進專案的「指令碼屬性」，之後更新程式就不用再填。

### 步驟 3：部署
1. 編輯器右上角 **部署 → 新增部署作業**。
2. 按「選取類型」旁邊的 ⚙️ → 選 **網頁應用程式**。
3. 設定：
   - **執行身分**：我
   - **誰可以存取**：**所有人**
4. 按 **部署**，複製 **網頁應用程式網址**（`https://script.google.com/macros/s/.../exec`）。
5. 用瀏覽器打開這個網址，看到「寶寶紀錄 bot 運作中 👶」就成功了。

### 步驟 4：把網址填到 LINE
1. 回到 [LINE Developers Console](https://developers.line.biz/console/) → 你的 channel → **Messaging API** 分頁。
2. **Webhook URL** 按 Edit，貼上剛剛的網址，按 Update。
3. 打開 **Use webhook**。
4. 掃同一頁的 QR code 加好友，傳 `說明` 試試看！

> 按 **Verify** 時可能會顯示錯誤（因為 Google 的網址會轉址），只要實際傳訊息有回應就沒問題。

### 更新到新版本
1. 打開試算表 → **擴充功能 → Apps Script**。
2. 把 `Code.gs` 的內容全部換成新版本，按 💾 儲存。
3. **部署 → 管理部署作業** → 按 ✏️ 編輯 → 版本選 **新版本** → **部署**。

這樣網址不會變，不用回 LINE 改設定，試算表裡的舊資料也都會保留。

token 已經存在「指令碼屬性」裡，所以更新時最上面那行不用再填。

> **從還沒有「報表」功能的舊版更新時**：舊版沒有把 token 存起來，所以**這一次**還是要把 token 填回最上面那行，或貼上後執行一次 `setup`。之後就不用了。
>
> 如果「報表」回覆說拿不到網址，可以到 Apps Script 的 **專案設定 → 指令碼屬性**，新增 `WEB_APP_URL`，值填部署網址（`https://script.google.com/macros/s/.../exec`）。

## LINE 沒回應時
1. 打開 Apps Script，上方函式選單選 **checkSetup**，按 **▶ 執行**。
2. 看下方「執行記錄」，照打 ❌ 的那一行處理：
   - **沒有 token**：把 Channel access token 貼到程式最上面那行，按 💾 儲存。
   - **token 不正確**：到 LINE Developers Console 重新複製 token。
   - **部署網址**：要跟 LINE Developers Console 的 Webhook URL 一樣。
3. 改完程式一定要 **部署 → 管理部署作業 → ✏️ 編輯 → 版本選新版本 → 部署**。
4. 還是不行的話，左邊選單 **⏰ 執行作業** 點最上面那筆 `doPost`，可以看到錯誤訊息。

## 安全提醒
- Channel access token 等於 bot 的鑰匙，不要分享給別人，也不要上傳到 GitHub。
- Apps Script 沒辦法驗證訊息是不是真的從 LINE 傳來的，所以**不要把部署網址分享給別人**。網址是一長串亂碼，別人猜不到。
- 報表連結後面帶著一組隨機密碼，每個聊天室不同。拿到連結的人可以看和新增那個聊天室的紀錄，所以只在家人的群組裡使用。
